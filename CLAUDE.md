# Reglas del proyecto CRC para Claude Code

## Módulo de contratistas (regla permanente, pedida por el dueño el 23/10/2026)

- **No leer, revisar ni actualizar por cuenta propia** la carpeta `14_Contratistas` del control de Drive: ni al empezar una tarea ni al terminarla. Solo se lee cuando el dueño lo pide.
- Si una tarea cambia tablas de CRC que el módulo usa (`empresas`, `sedes`, `unidades`, `puestos`, `personas`, `vinculos`, `roles`, `permisos`), al terminar se avisa al dueño **en una línea** («esta tarea cambió tablas que usa el módulo de contratistas»), se anota lo mismo en la bitácora de la tarea y se **espera su respuesta**. El dueño decide si hay que actualizar el esquema; no se actualiza la carpeta de contratistas por cuenta propia.
